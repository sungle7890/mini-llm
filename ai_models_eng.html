Axis 2

"What is it built from?" — model architecture

Usually what people mean by "model type." It splits into three families.

① Classical ML pre-deep-learning · still strong

  • Statistics / counting: frequency tables, Naive Bayes — this project's 01_bigram · lottery 09/10
  • Linear / logistic regression — the simplest predictors
  • k-NN — decide by nearest neighbors
  • Decision tree → Random Forest → Gradient Boosting (XGBoost · LightGBM) — still the strongest for tabular data — this project's 17/18
  • SVM, k-means (clustering)

② Neural networks (deep learning) deep learning

  • MLP (multi-layer perceptron) — this project's 02_mlp · stock 12~16
  • CNN (convolutional) — specialized for images
  • RNN / LSTM — sequential data (older; now mostly replaced by the Transformer)
  • Transformer — the backbone of modern LLMs (GPT · Claude) — this project's 03

③ Generative models a current focus

  • Autoregressive (GPT-style) — generate text one token at a time — this project's Transformer
  • Diffusion — image/video generation (Stable Diffusion, DALL·E, Sora)
  • GAN — image generation (older; two networks competing)
  • VAE — compression / generation

One-line map

Choose the tool to fit the data

The image of "AI = LLM" is strong these days, but in reality the strongest model differs by problem: tabular → boosting, images → CNN/Diffusion, text → Transformer. The key is not "always deep learning / LLM" but choosing the tool that fits the kind of data.

What this project showed again and again

Swapping the model only helps when "there is signal but the model can't extract it." When there is no signal (lottery), no model helps; when the signal is weak (stocks), switching to a stronger model (XGBoost) leaves out-of-sample unchanged and only makes overfitting (the illusion) worse.
